# Search Console workflow (cod-cheats.org)

## Setup

1. Open [Google Search Console](https://search.google.com/search-console) and add the **domain** property for `cod-cheats.org` if it is not already there.
2. Under **Sitemaps**, submit: `https://cod-cheats.org/sitemap.xml`

## After deploy

- Re-submit sitemap when major URL or article changes ship.
- Use **URL inspection** on `/`, `/products/`, `/articles/`, and top product detail pages after launch.
